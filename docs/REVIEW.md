# 建議 PR：建立三盞燈手機互動網站第一版

原儲存庫只有 README。本變更新增 React、TypeScript 與 Vite 網站，訪客點亮任一盞燈後即可用觸控或滑鼠繪畫、選擇顏色／粗細、移除物件、加入及拖曳貼圖，並上傳受大小與格式限制的圖片。

作品保存在本機瀏覽器，重新整理可恢復。畫面明確說明未與其他訪客共享；共享 repository 介面與 Supabase 資料、權限、防濫用及內容移除規格已備妥，但 adapter、資料庫、服務端 API 與管理頁仍需後續實作。

驗證：npm install、npm ci、npm run build、npm test（6 項通過）；Chromium 手機 390px 畫線、貼圖拖曳、重新整理持久化與無水平溢出檢查通過。另加入 GitHub Actions 的測試與建置流程，遠端執行結果需推送後確認。

審查重點：本機模式標示、儲存錯誤提示、畫布和操作區分離、圖片限制、共享權限規格。無需環境變數即可部署本機版至 Vercel。請依 README 的手機驗收清單實機操作；瀏覽器模擬不等同實體手機測試。
